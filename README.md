# sscope

今いるディレクトリで、どのスキルをどのエージェントで使えるか確認する Rust CLI です。

```sh
cargo install --path . --locked
```

使いたいディレクトリで実行します。Git リポジトリの外でもグローバルのスキルを表示します。

```sh
sscope
sscope --agent codex
sscope --agent "Claude Code"
```

通常表示では、左列にスキル名、右列にそのスキルを使えるエージェントが並びます。本体で確認できたスキルをプロジェクト、グローバルの順に表示します。同じ範囲のスキルを複数のエージェントで使える場合は、名前を1行にまとめます。たとえば `Codex（2か所） · Pi` は、両方のエージェントで使え、Codex にはそのスキルの読み込み元が2か所あるという意味です。

`sscope --agent codex` で絞ると、右列にすべての読み込み元のパスと、取得できた呼び出し条件が並びます。ラベルはスキルの置き場所を示します。たとえば `~/.agents/skills` には `[共通]`、`~/.codex/skills` には `[Codex]` が付きます。標準と異なる `CODEX_HOME` 配下のスキルなど、ほかの登録済みの探索先には `[設定先]` が付きます。探索先と照合できないパスはそのまま表示します。

端末では、同じエージェント名を一覧と詳細で同じ色にし、複数の読み込み元を示す `（2か所）` などの件数を太字にします。プロジェクトの見出しは緑、グローバルは紫です。パイプやファイルへの出力はプレーンテキストです。端末でも `NO_COLOR=1 sscope` で色を無効にでき、エージェント名・件数・読み込み元のラベルはそのまま読めます。

| 表示 | 確認できたこと |
| --- | --- |
| 本体で確認 | Codex、Pi、GitHub Copilot CLI に現在地で問い合わせた結果。Pi はオフラインで拡張と MCP を起動せず一覧を取得します。 |
| ローカルで検出（有効状態未確認） | 製品固有の設定や実行ファイルを検出し、既知の配置先で見つけた候補を一覧の末尾に表示します。本体に問い合わせられない場合もここに含みます。追加の探索先、組織のポリシーやクラウドの設定により、実際の一覧は変わります。 |
| 利用エージェント未特定 | 製品を特定できず、共有の `.agents/skills` に定義が見つかりました。 |

リポジトリルート配下（Git 外では実行ディレクトリ配下）のプロジェクトスキルは相対パスで、ホーム配下のグローバルスキルは `~` を使って表示します。スキル本文の指示や同梱スクリプトは実行しません。

## JSON 出力

`sscope --json` は全件を、`sscope --agent codex --json` は Codex の検出結果だけを、単一の JSON オブジェクトとして標準出力に書き出します。`--json` と `--agent` はどちらが先でも使えます。警告やエラーは標準エラー出力に出ます。

```sh
sscope --json > skills.json
sscope --agent codex --json
sscope --json --agent codex | jq -r '.agents[].skills[] | select(.scope == "project") | .name'
```

たとえば Codex がプロジェクトの `review-changes` を1件返した場合、JSON は次の形になります。

```json
{
  "cwd": "/work/sample",
  "agents": [{
    "name": "Codex",
    "evidence": "confirmed",
    "skills": [{
      "name": "review-changes",
      "scope": "project",
      "sources": [{ "path": "/work/sample/.agents/skills/review-changes/SKILL.md", "note": null }]
    }]
  }]
}
```

| フィールド | 内容 |
| --- | --- |
| `cwd` | 実行したディレクトリの絶対パス。 |
| `agents` | 検出結果の配列。エージェントも共有スキルも見つからなければ `[]`。 |
| `agents[].name` | エージェント名。共有スキルだけが見つかり、利用するエージェントを特定できない場合は `null`。 |
| `agents[].evidence` | `confirmed` はエージェント本体が返した結果。`candidate` はローカル配置で見つかった候補。 |
| `agents[].skills` | そのエージェントのスキル一覧。各要素に `name`、`scope`、`sources` が入り、検出件数がゼロなら `[]`。 |
| `scope` | `project`、`global`、`unspecified`（範囲未特定）のいずれか。 |
| `sources[].path` | 読み込み元。同じ範囲に同名の定義が複数あれば、同じ `sources` 配列に並ぶ。パスは検出時の値で、エージェントが相対パスや仮想パスを返した場合もその値を保持する。 |
| `sources[].note` | 呼び出し条件やパスに関する補足。補足がなければ `null`。 |

現在地や読み込み元のパスを UTF-8 で表せない場合は、標準エラー出力に理由を表示して終了します。このとき標準出力は空です。
