# sscope

今いるディレクトリで使えるエージェントスキルを、エージェント別、プロジェクト・グローバル別に一覧表示する Rust CLI です。

```sh
cargo install --path . --locked
```

使いたいディレクトリで実行します。Git リポジトリの外でもグローバルのスキルを表示します。

```sh
sscope
sscope --agent codex
sscope --agent "Claude Code"
```

通常表示ではスキル名を並べます。同じ範囲に同名の定義が複数あれば `×2` のように件数を表示します。`--agent` で絞ると各定義のファイルパスと、取得できた呼び出し条件を確認できます。

| 表示 | 確認できたこと |
| --- | --- |
| 本体で確認 | Codex、Pi、GitHub Copilot CLI に現在地で問い合わせた結果。Pi はオフラインで拡張と MCP を起動せず一覧を取得します。 |
| ローカル配置・有効状態未確認 | 製品固有の設定や実行ファイルを検出し、既知の配置先を走査した結果。本体に問い合わせられない場合にも表示します。追加の探索先、組織のポリシーやクラウドの設定により、実際の一覧は変わります。 |
| 利用エージェント未特定 | 製品を特定できず、共有の `.agents/skills` に定義が見つかりました。 |

リポジトリルート配下（Git 外では実行ディレクトリ配下）のプロジェクトスキルは相対パスで、ホーム配下のグローバルスキルは `~` を使って表示します。スキル本文の指示や同梱スクリプトは実行しません。
